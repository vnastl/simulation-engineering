This is our study of interest:
https://datacatalogue.ukdataservice.ac.uk/studies/study/5723#details

The documentation files from the webpage are in downloads. The data is stored in the zip files.

1) Check the webpage of the study. Unzip the data and check the downloads. Check which file provides the codebook and which file(s) provide the raw data.

2) Follow the instructions in CODEBOOK_TO_TEXT_PLAYBOOK.md to go from raw survey data + a PDF codebook to a persona.

3) If interviews are available, follow the instructions in INTERVIEW_TO_TEXT_PLAYBOOK.md.

4) Follow the instructions in TRACE_PLAYBOOK.md to walk one record through the pipeline and render every stage as a single self-contained HTML file
